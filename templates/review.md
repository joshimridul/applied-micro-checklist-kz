# Applied-micro writing audit

Use this template only for an audit the user requested. Omit unused boilerplate in the final response.

## Scope and review basis

Record the files, excerpts, exhibits, bibliography, and appendix material inspected. State which rendered pages were inspected, or that none were inspected. Identify supplied venue requirements and any material that was unavailable.

## Most consequential findings

For each finding, report:

> Location → memo rule ID → status → reader-facing problem → practical repair

Use only the memo's rules. Do not add research-design, identification, statistical, novelty, or literature-search recommendations.

## Coverage record

Use these statuses:

- **Needs revision:** an observable departure from the memo.
- **Satisfied in inspected material:** the inspected material follows the rule.
- **Explicit user/venue departure:** a supplied instruction is retained despite differing from the memo.
- **Not applicable:** the rule does not apply to the manuscript.
- **Not checked:** the required material or verification was unavailable.

For a whole-paper audit, cover all twelve topics. A topic can have more than one status when different rules have different evidence.
